Proyectos

Aplicación móvil de bienestar emocional

Proyecto de titulación desarrollado para ofrecer herramientas de seguimiento emocional y actividades de autocuidado.

Tecnologías: React Native, Expo, Node.js, Express, PostgreSQL, Jest y Postman.

Aula Virtual

Plataforma educativa con diferentes roles para administradores, profesores y estudiantes.

Watermaker

Aplicación web orientada al control y análisis de la huella hídrica.

Permite registrar consumo, consultar resultados, estadísticas y rankings, además de utilizar dashboards para visualizar información.

Tecnologías: React, JavaScript, Tailwind CSS, Node.js, Azure SQL, SQL Server, MongoDB y Power BI.

Sitio web desarrollado para un negocio de helados, enfocado en presentar productos, historia de la marca y medios de contacto.

Tecnologías: HTML, CSS y JavaScript.

Plataforma para gestionar actividades de voluntariado, participantes y disponibilidad de espacios o turnos.

Tecnologías: Django, PostgreSQL, JavaScript, HTML y CSS.
